Autharo support

A code is rejected

  1. Set Android date and time to automatic.
  2. Confirm that you selected the correct service and account.
  3. Wait for the next code and try once more.
  4. If the service replaced its setup key, delete the old entry and scan the new QR code.

Synchronization stopped

  1. Confirm that the device has network access.
  2. Open Settings → Sync.
  3. Select Sync now.
  4. If the session expired, select Sign in to existing account.

Recovery phrase

The recovery phrase contains 24 words shown by Autharo. It is not a Google recovery code. Autharo support cannot view, recover, or replace a phrase for a device that you cannot unlock.

Safe support requests

Use the support contact published with the application listing. Include the Autharo version, Android version, device model, and the exact error text. Do not include a password, recovery phrase, QR code, authenticator secret, backup, or one-time code.
