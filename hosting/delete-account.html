Account control

Delete a synchronization account

Use the Autharo application to authenticate the request. The website does not ask for your password or recovery phrase.

Delete the server account

  1. Open Autharo Authenticator.
  2. Open Settings.
  3. Open Your devices.
  4. Enter the account password when Autharo requests authorization.
  5. Select Delete account.
  6. Read the deletion summary.
  7. Enter the account password again and confirm deletion.
Local codes remain on this device. Account deletion removes the synchronized server account, encrypted server records, sessions, devices, shares, and associated account-security data. It does not wipe the local vault.

Delete local codes

To remove local data too, use Settings → Wipe this device after you delete the synchronization account. This action is permanent.

If you cannot open the application

Use the support contact published with the Autharo application listing. State the account email address. Never send your password, recovery phrase, authenticator secret, backup file, or one-time code.
